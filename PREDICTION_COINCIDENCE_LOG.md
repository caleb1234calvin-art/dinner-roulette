# Prediction & Coincidence Log

Updated: September 9, 2026

This file keeps explicit predictions separate from coincidences, parallels, and conceptual convergences. A coincidence can be meaningful or interesting without being counted as a prediction hit.

## Log rules

- A **prediction** should be stated before the outcome and remain falsifiable enough to evaluate later.
- A **category-level hit** can count when the anticipated class of event occurs even if details such as location or timing differ; the mismatch should remain recorded.
- A **coincidence / parallel** is logged for timing, thematic overlap, or independent convergence, but is **not scored as a prediction** unless an explicit prior prediction exists.
- Pending predictions remain pending until an outcome can actually be evaluated.
