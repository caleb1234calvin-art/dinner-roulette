# Dinner Roulette — Dark Dinner Icon Pack

The JPG assets in this folder are the approved dark-theme Dinner-tab icon set.

Visual identity:
- realistic claymation / tactile miniature food
- dark charcoal rounded-square tile
- cyan/teal glow from the left
- burnt-orange/terracotta glow from the right
- no restaurant logos, mascots, packaging, or text

These assets are reserved for Dinner mode when the app is using the dark theme. A separate light-theme pack may use the same objects/composition with a softer gray tile background.

Do not replace these files when adding light-theme variants. Keep light and dark assets as separate theme packs.
